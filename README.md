# Visitas PJ v0.2
Node + Postgres. Login por usuário e senha; consulta de CNPJ entre gerentes.

## Subir
1. Crie um banco Postgres gratuito (Supabase ou Neon) e copie a connection string.
2. Envie esta pasta para um repositório PRIVADO no GitHub (raiz com render.yaml).
3. Render: New > Blueprint > escolha o repositório.
4. Preencha DATABASE_URL (string do banco) e REGISTER_CODE (código de convite que você escolher).
5. Apply. As tabelas são criadas sozinhas no primeiro start.
